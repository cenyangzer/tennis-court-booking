# Tennis Court Booking System

## 项目简介

本项目是一个基于B/S架构的网球馆在线预约管理系统，为用户提供便捷的场地预约、支付和评价服务，同时为管理员提供全面的场馆管理功能。系统采用Flask框架开发，结合SQLite数据库实现数据持久化存储，具有界面友好、操作简便、功能完善的特点。

## 技术栈

- **前端技术**：HTML5、CSS3、JavaScript、Bootstrap 5
- **后端框架**：Python Flask
- **数据库**：SQLite + SQLAlchemy ORM
- **开发环境**：Python 3.12

## 功能模块

### 用户功能

用户模块提供完整的个人服务功能，包括用户注册与登录、场地信息浏览、在线预约、支付管理、预约记录查看和场地评价等。普通用户可以通过注册账号登录系统，查看所有网球场地信息包括场地名称、类型、位置、设施和价格等详情。用户在选择场地后可查看可用时段并进行预约，预约成功后可选择在线支付，支付完成后系统生成订单并记录预约信息。用户还可以在运动后对场地进行评价，为其他用户提供参考。

### 管理员功能

管理员模块提供全面的后台管理功能，包括用户管理、场地管理、预约管理、支付管理和评价管理等。管理员可以管理系统用户信息，包括查看用户列表、编辑用户资料和删除用户账号。场地管理功能支持添加新场地、编辑场地信息、上传场地图片和管理场地状态。预约管理功能允许管理员查看所有预约记录、取消预约和处理用户支付。支付管理功能支持为用户直接完成支付操作。评价管理功能允许管理员查看和删除用户评价内容。

## 数据库设计

系统包含以下核心数据表：

- **users**：用户信息表，存储用户账号、密码、姓名、联系方式等
- **courts**：场地信息表，存储场地名称、类型、位置、设施、价格等
- **bookings**：预约记录表，存储预约关联信息、预约时间、订单状态、支付状态等
- **reviews**：评价信息表，存储用户对场地的评价内容、评分、时间等
- **notices**：公告信息表，存储系统公告内容
- **court_availabilities**：场地可用性时段表，记录场地各时间段的可用状态

## 快速开始

### 方式一：直接启动

初始化数据库后直接运行服务器（无调试模式）：

```bash
python run_server.py
```

### 方式二：手动启动

1. 创建虚拟环境（可选）：

```bash
python -m venv .venv
.venv\Scripts\activate
```

2. 安装项目依赖：

```bash
pip install -r requirements.txt
```

3. 初始化数据库：

```bash
set FLASK_APP=app.py
flask init-db
```

4. 启动Flask服务器：

```bash
python run_server.py
```

### 访问系统

打开浏览器访问：http://127.0.0.1:5000

## 项目特点

本系统具有以下主要特点：采用B/S架构，用户无需安装客户端即可通过浏览器访问使用；前后端分离设计，代码结构清晰便于维护；响应式界面布局，适配不同尺寸的设备屏幕；完善的用户权限体系，区分普通用户和管理员角色；直观的操作界面，降低用户学习成本；完整的数据关联设计，确保数据一致性和完整性。
